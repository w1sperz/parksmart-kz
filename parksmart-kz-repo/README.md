# ParkSmart KZ

Умная парковка на основе ИИ: по видео с камеры система определяет, какие парковочные места свободны, а какие заняты. Водитель быстрее находит место, а владелец парковки видит загрузку и выручку.

Студенческий проект для конкурса «AI autumn». **Статус: прототип.** Данные в демо учебные, цифры в презентациях пока гипотезы.

## Что в репозитории

|Файл или папка|Что это|
|-|-|
|`smart-parking-kz-landing.html`|Лендинг проекта: идея, как это работает, тарифы, форма заявки (демо)|
|`smart-parking-kz-dashboard.html`|Панель администратора: схема парковки, история заездов, выручка, пиковые часы|
|`ai/detect.py`|ИИ-часть: находит машины на видео (YOLO) и определяет занятость мест|
|`ai/mark\\\_spots.py`|Помощник: отметить парковочные места мышью на кадре|
|`ai/spots\\\_config.example.json`|Пример файла с рамками мест|
|`assets/tailwind.css`|Стили (подключены локально, интернет для оформления не нужен)|
|`data/`|Сюда кладём видео парковки (в репозиторий не загружается)|
|`docs/`|Презентации и документы проекта|

## Как посмотреть демо

Откройте `smart-parking-kz-landing.html` двойным щелчком, оттуда есть ссылка на панель администратора. Без запуска ИИ панель работает в режиме **симуляции**: статусы мест и номера случайные, но при каждом запуске одинаковые.

## Как запустить ИИ-часть

1. Установите Python 3.10 или новее и библиотеки:

```
   pip install -r requirements.txt
   ```

2. Положите видео парковки в `data/parking.mp4`.
3. Отметьте парковочные места (мышью на первом кадре видео):

```
   python ai/mark\\\_spots.py --video data/parking.mp4
   ```

Мест должно быть не больше 20: ряды A–D по 5 мест, отмечайте их по порядку. Или скопируйте `ai/spots\\\_config.example.json` в `ai/spots\\\_config.json` и поправьте координаты вручную.

4. Запустите определение занятости:

```
   python ai/detect.py --video data/parking.mp4 --loop
   ```

Скрипт запишет `ai/output/spots.json` и `ai/output/frame.jpg`. При первом запуске YOLO сама скачает файл модели.

5. В другом окне терминала запустите локальный сервер и откройте панель:

```
   python -m http.server 8000
   ```

Адрес: `http://localhost:8000/smart-parking-kz-dashboard.html`. В шапке появится пометка «данные: ИИ (YOLO)», а ниже будет кадр с рамками.

Если открыть панель двойным щелчком (адрес `file://`), браузер не даст прочитать данные ИИ, поэтому нужен сервер из шага 5.

## Как это работает

1. YOLO ищет на кадре машины, мотоциклы, автобусы и грузовики.
2. Для каждого парковочного места считаем, какую долю его площади закрывает рамка машины.
3. Если закрыто не меньше 30%, место считается занятым (порог меняется параметром `--threshold`).
4. Результат записывается в `spots.json`, панель читает его каждые 5 секунд.

## Ограничения прототипа

* Модель YOLO стандартная, мы её пока не дообучали. На другом ракурсе камеры рамки мест придётся отметить заново.
* Номера машин не распознаются: в режиме ИИ в истории показывается прочерк.
* Оплата через Kaspi и датчики на ESP32 пока не реализованы.
* Форма заявки на лендинге демонстрационная, данные никуда не отправляются.
* Выручка и график пиковых часов в панели условные.
